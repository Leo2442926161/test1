## 1. 目标与边界

| 市场 | 路径 | 预合规目的 |
|---|---|---|
| US | FCC 47 CFR Part 15（有意辐射，典型 Subpart C；无意辐射视实验室判定） | 叠板后尽早暴露杂散/功率余量 |
| EU | RED 2014/53/EU：频谱（常见 **EN 300 328** 族，2.4 GHz）+ EMC（常见 **EN 301 489-1/-17** 等，以 OJEU 为准） | 同左；含告警态抗扰 |
| 生命安全 | UL 217 / 2034 · EN 14604 / EN 50291 | **不在本计划替代**；RF 与安规并行 |

Matter/Thread 互通资质 ≠ FCC/RED。无线级联跟报 ≠ 有线 multiple-station 声称。

## 2. 频段与射频工况

| 项 | EVT 假设 |
|---|---|
| 主射频 | 2.4 GHz Thread（802.15.4）± BLE 若固件开启 |
| 天线 | 板载/壳窗；净空 **≥5 mm**（绝对坐标草排） |
| 模组策略 | 优先芯片天线方案；若用预认证模组仍做**整机**评估（主机条件） |
| TX 模式 | 软件提供 RF 测试钩子：连续 TX / 占空可控 / 信道扫（对接 #3） |
| 级联 | 跟报突发计入「告警+TX」工况；不破峰值墙 600/1200 mA |

## 4. 预扫工况矩阵

| ID | 工况 | 测什么 | 通过判据（预合规） |
|---|---|---|---|
| RF-01 | Idle + Thread SED | 杂散/底噪 | 相对限值有余量（实验室标） |
| RF-02 | 最大占空 TX（测试钩子） | EIRP/功率谱 | 不超声明功率 |
| RF-03 | 信道扫（全支持信道） | 带边/邻道 | 无意外尖峰 |
| RF-04 | 报警态：蜂鸣+红脉 + TX | 辐射+电源噪声耦合 | 不劣于 RF-02 失控 |
| RF-05 | 级联跟报突发（单机模拟多帧） | 同 RF-04 | 与 L9 占空一致 |
| EMC-01 | 静电/传导抗扰（实验室能力内） | 告警态不误静音/不丢硬路径 | 声光 P0 保持 |
| EMC-02 | 射频场抗扰（若排期） | 误报/死机 | 无持续故障 |

桌面可先做：近场探头扫谐波、传导电流探头看 VSYS 尖峰（非正式报告，仅工程日志）。

## 5. 工程红线（布局已写进 PCB EVT 说明）

- 天线馈点最短；螺柱/电池远离净空锥  
- VLED/VSYS bulk 抑制可寻址刷新尖峰，降低宽带噪声  
- `HORN_DRV` 回流不穿 RF 参考地敏感区  
- 禁为预扫临时加有线互联测试座当「产品接口」
