## Overlay 政策

允许写入草案脚号的只有这五处：

| 信号 | 草案脚 | 文件 |
|---|---|---|
| `LED_RGB_EN` | P2.08 | `boards/evt_pins_placeholder.overlay` |
| `LED_RGB_DATA` | P2.06 | 同上 |
| `LED_RGB_CLK` | P2.07（单线 **DNP**） | 同上 |
| `LED_STATUS` | P0.01 | 同上 |
| `VBAT_SENSE` | P1.06 / AIN2 | 同上 |

该文件**不会**被 Zephyr 自动套用。`app.overlay` 仍不写脚号，DK 冒烟目标不复用这组脚。  
其余信号保持 `PIN_TBD`，不进 overlay。overlay 里没有 `GPIO_ACTIVE_*`（不把负载开关极性写成已确认），也没有 ADC 增益或分压电阻。

## 1. 调试口

骨架产测先走 **RTT/SWD**。`UART_DBG` 的 SoC 脚未冻（对齐一页 **ICD-03**），等 #17。钩子 JSON 还没接到 RTT。

| 项 | 草案 | 确认 |
|---|---|---|
| 顺序 | SWD 优先 | 骨架用 RTT/SWD。不绑 `UART_DBG` |
| SWD | 模组 `SWDIO` / `SWDCLK` / `RESET` | 草案。不写 SoC GPIO 号。量产可以 DNP 隔离电阻（无阻值） |
| `UART_DBG` TX / RX | `PIN_TBD` | **未冻**。等 #17。不进 overlay |
| 波特率、RTT 通道号 | 未填 | 未锁 |
| 钩子是否与日志同口 | 未接 | 字段名仍是 `hush_*` / `alarm_relay_*` / `relay_enable` |

## 2. `LED_RGB_EN`

| 项 | 草案 | 确认 |
|---|---|---|
| SoC 脚 | P2.08 | 草案脚号，已写入非自动 overlay |
| Idle | 0 | **已冻** |
| 报警 | 先 EN=1，再出帧 | **已冻** |
| 有效电平 | 跟负载开关料号 | **未锁**。overlay 不写极性 |
| 被切断的电源 | VLED | 确认切的是 VLED。开关料号未锁 |

## 3. 灯环

| 项 | 草案 | 确认 |
|---|---|---|
| 拓扑 | 单线默认 | 确认单线默认。`LED_RGB_CLK` **DNP** |
| `LED_RGB_DATA` | P2.06 | 草案脚号，已写入非自动 overlay |
| `LED_RGB_CLK` | P2.07 | 草案脚号。单线方案不贴 |
| `LED_STATUS` | P0.01 | 草案脚号，已写入非自动 overlay。中心点，不经灯串 |
| 灯珠料号、电平转换、VLED 来源 | — | **未锁** |
| 段数与 ch0 | 文案 64 段 | 地址等 #17。本骨架不编码 |

`LED_RGB_*` 不与 `HORN_DRV` / `RF_WAKE` 复用（逻辑约束，不是新脚号）。

## 4. `VBAT_SENSE` 与产测焊盘

`P1.06/AIN2` 来自归档网表 v0.1 的 `VBAT_SENSE` 行。ICD-02 写过：不能把那张旧表当成已冻 Pin。硬件本次把它记为电池告警 ADC 草案，布线仍可在同一 AIN 组内改。

| 项 | 草案 | 确认 |
|---|---|---|
| `VBAT_SENSE` | P1.06 / AIN2 | 草案。ADC，分压+RC 的**输入**。不是片内原始 VBAT 轨（不用 `NRF_SAADC_VBAT`） |
| 分压电阻、采样焊盘 | — | **未锁**。overlay 不写阻值和增益 |
| 开盖 | 仓盖只动 `COVER_DET` | 不切断 VBAT |
| 电流分流 | EVT 工装 | 位置与阻值未锁。`TC-CASCADE-PWR-01` 仍无读数 |
| `CONTAM_TP` | 焊盘 | 只测点，**不占 GPIO**。不进 overlay |
