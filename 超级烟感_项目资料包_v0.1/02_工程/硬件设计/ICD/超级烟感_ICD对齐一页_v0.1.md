骨架文首仍写「对齐 ICD v0.1.4a、FSM v0.3」。软件索引的现行 ICD 已是 **v0.1.7**。v0.1.7 相对灯总线多出来的是 SED **L9**、Hush、无线级联语义，没有改下面四只灯脚。

正式版说明里的冻结网表 v0.2.0-freeze 与骨架灯脚相同，并使用逻辑名 `HW_FAULT_SNS`。本页以骨架 v0.1.2 为硬件侧对照本。

---

## 一致

| 项 | ICD v0.1.7 | 网表骨架 v0.1.2 |
|---|---|---|
| 灯总线 | 64×可寻址 RGB；单线默认 / SPI 备；不加 96 段 | 64×可寻址 RGB；单线默认 / SPI 备 |
| `LED_STATUS` | P0.01，直驱，不经灯串 | P0.01，同左 |
| `LED_RGB_DATA` | P2.06，单线 DOUT / SPI MOSI；禁与 HORN / RF_WAKE 复用 | P2.06，同左 |
| `LED_RGB_CLK` | P2.07，SPI SCK；单线方案 **DNP** | P2.07，同左 |
| `LED_RGB_EN` | P2.08；Idle=0；Alarm 先置 1 再出帧 | P2.08；Idle 默认关；Alarm 先置位再出帧 |
| 作废默认轨 | 删除 `LED_I2C_*` / 单色 I2C 灯驱 | 删除 `LED_I2C_SCL/SDA`、`LED_DRV_INT` |
| 硬路径 | 判决→声光 **≤50 ms**，不经 Thread | `HORN_DRV` + 报警红 **≤50 ms**，不经 Thread |
| 无新互联脚 | 无有线 `INTERCONNECT` | 未增加互联网；灯改总线，不改级联脚 |
| 传感逻辑名（除故障名，见下） | `OPT_I2C_*` `OPT_INT` `OPT_DISC_ADC` `OPT_RAIL_SEL` `CO_SIG` `CO_BIAS_EN` `VBAT_SENSE` `HORN_DRV` `BTN_TEST_MUTE` `COVER_DET` `CONTAM_TP` `SWD` | 同一串，写明相对 v0.1.1 不变 |
| 壳体 | 白壳主 SKU | 白壳主 SKU |
| 详设灯脚 | §6 复述上述四只脚，并写明由硬件网表最终确认 | 与这四只脚一致 |

软件宿主（`fw-hush-relay-0.1.0-evt`）执行的是 SED 钳位、Hush、离线跟报这些 **逻辑**，不是上述 GPIO。缺口清单 SW-08 / SW-09 已写：无 ADPD、无 TGS5141、无 `OPT_RAIL_SEL` 驱动，无 64 段像素帧，无 P2.06 波形。

## 差异 / 开放项

| ID | 项 | 现状 | 等谁 |
|---|---|---|---|
| ICD-01 | 故障逻辑名 | 骨架继承行写 **`HW_FAULT`**。ICD v0.1.7 与原理图正式版说明写 **`HW_FAULT_SNS`**。非现行网表 v0.1 曾把逻辑名 `HW_FAULT_SNS`、网名 `HW_FAULT` 分开，骨架 v0.1.2 没有把这句话重写回来 | 硬件改骨架一行；软件不改 ICD |
| ICD-02 | 非灯脚未在骨架重列 | ICD Pin 节写「其余同 v0.1.3」。骨架只给灯脚四行，其余网名一行带过，**没有**再印 P2.01 / P1.04 等脚号。不能把非现行 v0.1 的脚表当成 v0.1.2 已冻 Pin | 料号与封装锁定后由网表逐脚回写。此前软件维持「其余同 v0.1.3」为草案 |
| ICD-03 | `UART_DBG` | ICD 信号表有 `SWD/UART_DBG`。骨架继承行只写 `SWD` | 产测口随 #15 板级工程一并确认，本页不新编脚号 |
| ICD-04 | 光学双轨用词 | ICD 基线：EVT 双轨，ADPD I2C 与 TI 分立 ADC 互斥。骨架只有 `OPT_*` 网名，正文没有写 TI / ADPD | 订单料号见 [`BOM/超级烟感_BOM缺口表_v0.1.md`](../BOM/超级烟感_BOM缺口表_v0.1.md)，两轨都是 **缺口/未锁** |
| ICD-05 | CO 器件名 | ICD：TGS5141 主、NAP-508 备。骨架只有 `CO_SIG` / `CO_BIAS_EN` | 实价堵 [#8](https://github.com/Leo2442926161/test1/issues/8)。料号 **缺口/未锁** |
| ICD-06 | 电池 | ICD：CR123A×2 并联。骨架 v0.1.2 正文未重写电源域；VLED 写「VSYS 或 3V3」 | 电芯料号 **缺口/未锁**。接法以正式版说明的并联为准，直到骨架补一行 |
| ICD-07 | 底边灯 | 骨架：细环 64 颗之外，底边可共用尾段或另加 4–8 颗（结构定）。ICD 已冻配置只锁 64×RGB，不把 4–8 写进颗数 | [#17](https://github.com/Leo2442926161/test1/issues/17) 结构定之前，BOM 不单列这几颗 |
| ICD-08 | 文首版本指针 | 骨架仍写 ICD v0.1.4a、FSM v0.3，以及「绝对坐标仍 3–5 日冻」。现行 ICD 是 v0.1.7；FSM 文件是 v0.3，文内有 v0.3.1 补丁节。螺柱现行坐标已在 `PCB/超级烟感_绝对坐标草排_v0.1.1.md`：**R=41.6×3** | 下次改骨架时只改文首。本页不改网表。R=48 已作废 |
| ICD-09 | 电流 | ICD 写峰值墙 600/1200 mA，以及 L4 的 `LED_STATUS` 平均电流限额。这些是 ICD / 寿命表里的**设计限额**。骨架不写 mA。硬件实测表是空的 | [#15](https://github.com/Leo2442926161/test1/issues/15)。本页不填毫安 |
| ICD-10 | 上板 | 四只灯脚两边一致。宿主没有 NCS 工程，不翻转 P2.06 / P2.07 / P2.08 | [#15](https://github.com/Leo2442926161/test1/issues/15) |

v0.1.4a 曾把 `LED_RGB_EN` 写成「可选」。v0.1.7 与骨架 v0.1.2 已一致：Idle 默认关，Alarm 先置位再出帧。
