**目标**：EVT 可投板布局准则（非最终 Gerber）

---

## 1. 板型与叠构（草案）

| 项 | EVT 建议 |
|---|---|
| 主控板 | 圆形/近圆，直径对齐结构内腔（草排 ~Ø110–120 mm 可用区，待结构确认） |
| 灯环 | **独立柔灯板或硬灯环**（64 段），FPC/板对板接到主控；**禁** Nest 式大环面灌光整板 |
| 叠构 | 主控 **4 层**（信号-GND-电源-信号）优先；灯环 2 层可接受 |
| 电子栈高 | ≤ **28 mm**；整机厚 ≤ **45 mm** |
| 电池 | CR123A×2 **侧置**夹持；远离天线窗 |

---

## 2. 分区（Floorplan）

```
        [天线窗 / 净空≥5mm]
              RF 匹配
    CO腔 ← 主控+电源 → 光学暗室(TI)
              蜂鸣腔
        [电池仓侧置]
   灯环绕周（柔板，经 LED_RGB_*）
```

| 区 | 规则 |
|---|---|
| RF | 天线馈点到芯片最短；净空锥 ≥5 mm；金属螺柱避开辐射瓣 |
| 光学 | TI 分立：LED/PD 按光路夹角；遮光与结构暗室对齐；ADPD 互斥不贴 |
| CO | 气路开孔与传感器窗口；加热/偏置走线远离 RF |
| 电源 | VSYS bulk 近电池座；VLED bulk **就近灯串入口**；地以星+平面 |
| 蜂鸣 | 驱动管近喇叭；回流不穿敏感模拟 |
| 灯 | `LED_RGB_DATA` 串阻就近 SoC；单线电平按料号；`EN` 开关近 VLED |

---

## 3. 电源峰值墙（布局侧）

| 墙 | 限值 | 布局动作 |
|---|---|---|
| 持续 ≤600 mA | 电池夹/FPC 线宽按 **≥1 A** 余量设计 | 降 IR；并联电芯等长 |
| 脉冲 ≤1200 mA | VLED/VSYS 各 ≥100–220 µF 低 ESR 就近 | 吸收可寻址刷新尖峰 |
| 级联同响 | 多机蜂鸣+TX | EVT 测 N 台同响压降（TC-CASCADE-PWR-01） |

可选：高边电流采样电阻焊盘（默认 NC）。

---

## 4. 射频与级联

- 无互联连接器、无 `INTERCONNECT` 铜皮。  
- Thread/自研共用天线路径时，匹配网络一版走线，固件切协议。  
- 级联失败不得依赖 PCB 上的“备份有线”。  
- 认证：无线跟报 ≠ UL/EN 有线 multiple-station 声称。

---

## 5. 可测性（DFT）

| 点 | 用途 |
|---|---|
| SWD + UART_DBG | 烧录/日志 |
| VBAT / VSYS / 3V3 / VLED 测点 | 电流墙验证 |
| CONTAM_TP | 污染 |
| OPT / CO 模拟测点 | 产测夹具 |
| 灯环首尾跳线焊盘 | 开路定位 |

全环 64 满白：**仅工装外电**（L6）；量产夹具不得用电池拉满白。

---

## 6. Listing / 认证绑定

- 量产光学 **绑 TI 分立**；ADPD 仅 EVT/$99 备选板。  
- FCC/RED：天线增益与匹配以预扫报告为准（预算待 Leo）。  
- 不宣称 Matter=生命安全互联。

---

## 7. 风险与工期

| 风险 | 缓解 |
|---|---|
| 白壳导光效率低 → 顶 L2 电流 | 先结构导光，不靠加电流 |
| 64 RGB + 蜂鸣 + TX 压降 | bulk + 线宽 + SED L5/L9 |
| 天线被灯环/螺柱挡 | 绝对坐标草排互检结构 |
| CO/LED 数据空 | 实价/实测回填前不闭 #4 末两项 |

**Gerber**：结构开孔+绝对坐标终锁 + 叠板评审后 **5–7 工作日**。本说明可支持 EVT 布线开工。
