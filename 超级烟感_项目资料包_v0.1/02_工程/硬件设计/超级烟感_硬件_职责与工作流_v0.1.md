## 4. 工作流（顺序）

1. **G2**：选型一页 → 会同采购交期价 + 财务成本 → Leo 锁料号（含 [#8](https://github.com/Leo2442926161/test1/issues/8) RFQ）
2. 网表 / SED 冻结后：ICD 对齐、绝对坐标叠板互检（结构 [#17](https://github.com/Leo2442926161/test1/issues/17)）
3. **G3**：原理图评审 →（解除禁令后）EDA / Gerber → EVT 联调（[#15](https://github.com/Leo2442926161/test1/issues/15) 电流实测有板才做）
4. 输出进仓：`02_工程/硬件设计/{BOM,ICD,PCB,原理图,电源射频}`。固件测点确认看 `firmware/` 与软件 `HARDWARE_NEEDED`

- **锁定**：nRF54L15 + TGS5141。量产默认 TI 分立光学；EVT 双轨（ADPD 为 $99 备选）

- **风险 / 工期**：#8 Leo 询价目标约 10-24；#15 / #17 约 10-29。无板不出 mA / hex。未锁料号不出 Gerber
