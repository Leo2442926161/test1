# 超级烟感 · 原理图网表骨架 v0.1

**状态**：草案 → 目标 3–5 工作日冻网表（不下单）  
**基线**：ICD v0.1.2/0.1.3 逻辑名 + AN54LQ-15 Pin 草案；光学 EVT 双轨互斥；COVER_DET 必选  
**主控**：Raytac AN54LQ-15（nRF54L15）

## 1. 电源域
| 网名 | 电压 | 来源 | 负载 |
|---|---|---|---|
| VBAT | 2×CR123A 串联/并联待定* | 电池仓 | 主供电 |
| VSYS | VBAT→理想二极管/防反 | 保护 | 全机 |
| VDD_3V3 | LDO/DC-DC → 3.3V | VSYS | 模组、逻辑、ADPD/分立、运放 |
| VDD_CO | 受 `CO_BIAS_EN` 门控 | VDD_3V3 | TIA/偏置（休眠关断） |
| AGND/DGND | 单点星接烟腔/射频旁 | — | 模拟与数字分区 |

\* 串联约 6V / 并联约 3V：EVT 默认**并联 3V**（降压简单、换电友好）；若峰值电流不够再评估串联。结构开盖不断电=电池正负极不经仓盖开关切断，仅 `COVER_DET` 检测。

## 2. 模组与调试
| 网名 | 模组脚/SoC | 备注 |
|---|---|---|
| VDD_NRF | VDD | 去耦按 Raytac |
| SWDIO / SWDCLK / RESET | 调试 | 量产可 DNP 电阻隔离 |
| ANT | 模组芯片天线 | Keep-out ≥5 mm（结构已冻） |

无外挂 `RF_RESET`；Thread WAKE **不得**与 HORN/LED 共用。

## 4. 光路双轨装配规则
- **ADPD 轨**：装 ADPD188BI + I2C/INT；`OPT_DISC_*` 与前端 DNP；`OPT_RAIL_SEL`=性能电平  
- **TI 分立轨**（$89 量产默认意向）：装分立光电；ADPD DNP；`OPT_RAIL_SEL`=成本电平  
- 外壳/烟腔共型，只换光学子组件（结构已认）

## 5. 本地硬路径
`HORN_DRV` / `LED_*`：MCU GPIO →（MOS）→ 负载；**禁止**经 Thread/Matter 门控；端到端 ≤50 ms（软件/测试已冻探针）。

## 6. 给结构的堆叠包络（待 3D）
模组(≤1.8mm) + 主板 + 光学子板 + CR123A×2 + 压电独立声腔 + 细环导光；硬件预留 **+0.5 mm**；总厚目标 ≤45 mm 由结构卡。天线上方非金属窗；电池远离天线。
