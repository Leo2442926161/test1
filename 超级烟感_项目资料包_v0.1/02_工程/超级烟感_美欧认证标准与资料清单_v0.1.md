# 超级烟感 · 美欧认证标准与资料清单 v0.1

**产品**：家用可换电 Smoke+CO 组合报警器（Matter/Thread，白壳，本地声光优先）  
**市场**：US + EU（主）；UK 另见 UKCA 备注  
**状态**：工程基线清单，**非法律意见**；正式路径以选定 Notified Body / NRTL 报价为准  
**日期**：2026-10-22 Asia/Shanghai · 硬件主导 · G2/G3 共用

---

## 0. 认证流总览（建议顺序）

```
选型锁料 → 原理图/PCB/结构冻结 → 预合规(射频/安规桌面)
    → 送样 NRTL(UL) / NB(EU)
    → 型式试验(烟/CO 隧道 + 电气 + 射频)
    → 工厂检查(UL Follow-up / EU FPC)
    → 证书 + 铭牌/说明书定稿 → 量产放行
```

| 阶段 | 谁主导 | 产出 |
|---|---|---|
| G2 | 硬件+采购+财务 | 认证预算、实验室短名单、关键料是否可认证 |
| EVT | 硬件+测试+结构 | 预测试报告、缺口清单 |
| DVT/PVT | 测试+硬件 | 正式送检样机、整改 |
| G4 | 量产交付+测试 | 证书有效、产线一致性 |

**Matter 认证 ≠ 生命安全认证**：Matter/CSA 只证明互联互操作；**UL/EN 烟感 CO 证书不可替代**。

## 1. 美国（UL / FCC）— 标准清单

### 1.1 生命安全（必选）
| 标准 | 适用范围 | 本产品 |
|---|---|---|
| **UL 217** | Single/Multiple Station Smoke Alarms | 烟报警（光电）必测 |
| **UL 2034** | Single/Multiple Station CO Alarms | CO 报警必测 |
| 组合机 | 同时符合 UL 217 **与** UL 2034 | Listing 类别常归 CO 或组合表述，以 UL 目录为准 |

相关引用（非替代主标准）：NFPA 72（安装规范，影响说明书安装位置表述）；部分辖区建筑规范要求 Listed to UL 217/2034。

### 1.2 无线与电磁（必选，因 Thread/BLE）
| 标准/法规 | 说明 |
|---|---|
| **FCC Part 15**（典型 Subpart C 有意辐射） | 2.4 GHz Thread/BLE 发射 |
| FCC Part 15B（若适用） | 数字设备无意辐射 |
| ISED（加拿大，若售 CA） | RSS-247 等，常与 FCC 同测扩展 |

### 1.3 常一并评估的安全/部件
| 项 | 说明 |
|---|---|
| 电池与电源路径 | CR123A 可换电：极性保护、开盖不断电策略、低电信号符合 UL 217/2034 |
| 压电蜂鸣声压/时序 | 烟：典型 3 脉冲模式；CO：4 脉冲模式（与标准一致，固件勿混） |
| 塑料/阻燃 | 外壳材料 UL 94 等级按实验室要求 |
| 关键元器件 | CO 传感器、光电组件需可追溯规格与可靠性数据 |

### 1.4 美国认证流（简化）
1. 选 NRTL（UL Solutions / Intertek / ETL 等）开案 → UL 217 + UL 2034 组合  
2. 提交 Construction / 原理图 / PCB / BOM / 说明书草稿  
3. 送样（数量以开案信为准；CO 类常见十余台量级 + 拆解样）  
4. 烟隧道 + CO 浓度/响应时间 + 误报抗扰 + 环境/电气  
5. 射频：FCC 测报（可并行另一家）  
6. 初始工厂检查 → Listing → 量产 Follow-up

## 2. 欧盟（CE）— 标准 / 指令清单

### 2.1 生命安全（必选）
| 标准 | 法规框架 | 本产品 |
|---|---|---|
| **EN 14604** | **CPR**（建筑产品，EU 305/2011） | 烟报警装置；需 **DoP** + 常需 NB 参与的合格评定 |
| **EN 50291-1** | 家用 CO 电气装置 | 家用 CO；组合机必须同时满足 |
| EN 50291-2 | 房车等 | **非**本一代默认范围则不做 |

组合 Smoke+CO：实验室按 **EN 14604 + EN 50291-1** 双测。

### 2.2 无线电设备指令 RED 2014/53/EU（必选）
典型协调标准族（以 OJEU 现行清单为准，送检前核对）：
| 域 | 常见标准举例 |
|---|---|
| 射频 | EN 300 328（2.4 GHz 宽带） |
| EMC | EN 301 489-1 / -17（或现行替代号） |
| 健康/RF 暴露 | EN 50663 / EN 62311 等（按设备类型） |
| 电气安全 | EN 62368-1（视 NB/实验室对电池供电报警器的引用） |

### 2.3 横向合规
| 法规 | 说明 |
|---|---|
| RoHS（2011/65/EU） | 有害物质；需材料声明 |
| REACH | SVHC 信息传递 |
| WEEE | 注册/标志（销售国义务） |
| 包装指令 | 包材标识 |

### 2.4 欧盟认证流（简化）
1. 烟感走 **CPR + EN 14604**（Notified Body）  
2. CO 走 **EN 50291-1** 测试报告  
3. 无线走 **RED**（模组若已有 RED，整机仍常需整合评估/DoC）  
4. 汇总结 DoC（+ DoP for CPR）→ CE 铭牌 → 技术文件存档 ≥10 年  

**UK**：若售英国，另做 **UKCA**（BS EN 14604 / BS EN 50291-1 等），勿默认 CE=UK。

### 3.2 说明书与用户材料（市场+硬件互检）

## 4. 对本案的特别提醒（风险）

| 风险 | 说明 | 动作 |
|---|---|---|
| RGB 酷炫光效 | 不得削弱标准要求的可视报警指示语义 | 报警红脉优先；认证样机固件可锁「认证 profile」 |
| Matter 文案 | 易被误读为联网代替报警 | Listing/说明书严格按已冻禁区 |
| 可换电 CR123A | 低电、极性、开盖不断电均在 UL/EN 审查范围 | 结构 COVER_DET + 电源路径已按此设计 |
| CO 传感器授权 | 无厂家支持难过气测与一致性 | **G2 仍卡 CO 实价/授权** |
| EN 14604 = CPR | 流程重于普通 CE 自声明 | 早定 NB，勿按「只做 RED」规划 |
| 双光学轨 | EVT ADPD/TI 可能要说明主测配置；量产默认 TI 需与证书配置一致 | 证书绑定光学配置 |
