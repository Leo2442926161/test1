## 2. 冻结网表 v0.2.0-freeze

相对骨架 v0.1.2：**无新增逻辑脚**；级联不引入 `INTERCONNECT`。

### 2.1 路径光（已冻）

| 逻辑名 | SoC Pin（草案） | 网名 | 电气 | 备注 |
|---|---|---|---|---|
| LED_RGB_DATA | P2.06 | LED_RGB_DATA | 单线 DOUT / SPI MOSI | 禁与 HORN/RF_WAKE 复用 |
| LED_RGB_CLK | P2.07 | LED_RGB_CLK | SPI SCK | 单线方案 **DNP** |
| LED_RGB_EN | P2.08 | LED_RGB_EN | GPIO→负载开关 | Idle 默认关；Alarm 先置位 |
| LED_STATUS | P0.01 | LED_STATUS | GPIO/PWM 直驱 | 中心点；不经灯串 |

### 2.2 传感 / 电源 / 人机（继承，正式列入）

| 逻辑名 | 方向 | 备注 |
|---|---|---|
| OPT_I2C_SDA/SCL | 双向 | ADPD 轨 |
| OPT_INT | IN | 光学就绪/故障 |
| OPT_DISC_ADC | IN | TI 分立轨 |
| OPT_RAIL_SEL | IN | 识光路轨 |
| CO_SIG | IN | CO 模拟 |
| CO_BIAS_EN | OUT | CO 偏置 |
| VBAT_SENSE | IN | 电池告警 |
| HORN_DRV | OUT | P0 蜂鸣；硬路径 ≤50 ms |
| BTN_TEST_MUTE | IN | 自检/消音（烟 Hush；CO 禁） |
| COVER_DET | IN | 仓盖必选 |
| HW_FAULT_SNS | IN | 硬件故障 |
| CONTAM_TP | 测点 | 污染检测 |
| SWD / UART_DBG | 调试 | 产测 |

**删除（非默认）**：`LED_I2C_SCL/SDA`、`LED_DRV_INT`、任何有线多站 `INTERCONNECT_*`。

### 2.3 硬路径

判决 → `HORN_DRV` + 报警红段：**≤50 ms**，不经 Thread ACK。Alarm：`LED_RGB_EN=1` → 再出 RGB 帧。

## 3. 电源与峰值墙（设计说明）

电池：CR123A×2 并联，名义 ≈3.0 V / 3000 mAh（以实测为准）。

| 墙 | 限值 | 计入 |
|---|---|---|
| 持续 >100 ms | **≤600 mA** | 灯 + 蜂鸣 + Thread/级联 TX |
| 短脉冲 <20 ms | **≤1200 mA** | 可寻址刷新尖峰 + 射频突发 |

固件执行 SED **L1–L9**（见寿命表）；超限限流/降亮。原理图预留电流采样焊盘（EVT 可不贴）。

## 4. 无线级联（一期 · 与产品范围锁一致）

| 项 | 约束 |
|---|---|
| 产品 | 同品牌无线跟报（Thread/自研），**断云仍可**；用户可关；多机 Hush **不压他机** |
| 管脚 | **不改网表**；无有线多站 |
| Matter | 仅状态/通知，≠消防互联声称 |
| SED | **L9**：跟报占空软件限；报警态 TX 不破峰值墙；失败不挡本地声光 |
| 风险 | N 台同响压降 → RF 灵敏度跌；EVT 挂 TC-CASCADE-PWR-01 |

## 5. Hush（硬件无关新脚）

烟：8–10 min（默认 9）自动恢复；不关危急声光。CO：**禁 Hush**（按键拒绝）。硬件仅提供 `BTN_TEST_MUTE`；策略在固件/ICD。
