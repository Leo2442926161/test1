## 1. 电流积木（设计假设）
| 块 | 平均/峰值 | 说明 |
|---|---|---|
| Thread SED + 传感 Idle | **~0.10 mA** avg | 目标量级；含 CO 偏置占空 |
| 灯串关电漏电 | **~0** | `LED_RGB_EN=0` 强制 |
| 单颗 RGB 满白 | ~45 mA | 峰值积木；**禁止 64 颗同时满白** |
| 单颗冷白 25% | ~8–12 mA | RingSweep 用 |
| 压电蜂鸣 | 80–150 mA | 报警时 |
| 可寻址满帧刷新尖峰 | +总线尖峰 | 靠 bulk 电容；计入峰值墙 |

**硬件峰值墙（并联 CR123A）**  
- 持续（>100 ms）：**≤ 600 mA**  
- 短脉冲（<20 ms）：**≤ 1200 mA**  
超限由固件限流/降亮；原理图加电流采样可选（EVT NC）。

## 2. SED / 占空比限额（软件必须执行）
| ID | 限额 | 适用 |
|---|---|---|
| L1 | **同时点亮 ≤ 8 段**（RingSweep/Path）；窗口外全灭 | `RingSweep_Night` / PathGuide |
| L2 | Path/环扫单段亮度 **≤ 25%**（冷白）；周期 1.0–1.5 s | 非报警 |
| L3 | 连续环扫 **≤ 60 s**，然后冷却 ≥ 5 min（或累计 5 min/小时） | 防演示耗电 |
| L4 | Idle：`LED_RGB_EN=0`；仅 `LED_STATUS` **≤ 0.5 mA** avg 呼吸 | 夜间待机 |
| L5 | 报警：同时点亮 **≤ 16 段**，红/橙 **≤ 70%**；可与蜂鸣叠加，但总电流守 600 mA 墙 | Pulse_* P0 |
| L6 | **禁止**全环 64 段 RGB 满幅；产测全亮仅工装外接电源 | 工厂 |
| L7 | OTA/Thread 高峰时非 P0 光效降到 L1/L2 一半 | 与射频错峰 |
| L8 | `voice_enable` 无关：声光限额不变；语音功放另计（若有，Idle 关） | — |

粗算 RingSweep：8×10 mA ≈ **80 mA** 脉冲串，1.2 s 周期内平均视 chase 占空 ≈ **25–40 mA** avg（扫动期间）。

## 3. 寿命表（名义 3000 mAh，100%→换电阈值未含温度/自放）
| 场景 | 日均额外电量 | 估算寿命 | 备注 |
|---|---|---|---|
| A. 纯 Idle（L4） | ~2.4 mAh/日（0.1 mA） | **~3.4 年** | 理想上界 |
| B. 典型家用：路径指引 2×30 s/日 + 月自检 | ~1.5–3 mAh/日 光 + Idle | **~2.0–2.5 年** | 目标带 |
| C. 重度演示：路径 20×60 s/日 | ~20–40 mAh/日 | **~2–4 月** | 须产品限次或演示模式外电 |
| D. 报警 10 min/月 + B | 蜂鸣主导 | 仍 ≈ **B** | 报警稀事件 |
| E. 违规全环白 1 h | 数百 mAh | 不可接受 | 固件禁止 |

**结论**：在 **L1–L8** 下，家用换电目标 **≥ 2 年** 可谈；酷炫密度靠限额不是靠堆电池。实测 EVT 后出 v0.2。

## 4. 给软件的回写接口
请将 L1–L8 写入 ICD/FSM 占空比节；RingSweep 默认：window=6–8、brightness≤25%、period=1.2 s、max_continuous=60 s。
