## 1. 叠层（EVT 主控板 · 4 层）

| 层 | 用途 | 备注 |
|---|---|---|
| L1 | 信号 + RF 匹配/天线馈 | 天线区禁无关铜 |
| L2 | GND 完整平面 | 蜂鸣/灯回流就近过孔进地 |
| L3 | 电源（VSYS / 3V3 / VLED 分割） | VLED 岛近灯环接插件 |
| L4 | 信号 + 次要走线 | 密走线优先底层 |

板厚名义 **1.0 mm**（可 0.8–1.2，与结构电子栈 ≤28 / 总厚 42 复核）。铜厚默认 1 oz；电池/VLED 大电流路径可局部加宽或 2 oz 评估。

灯环柔板：**2 层**；`LED_RGB_DATA` 串阻在主控出脚侧；铜皮绕开天线窗 (0,+52)。

---

## 2. 禁布 / 净空（坐标 v0.1.1）

| 区 | 规则 |
|---|---|
| 天线柱 (0,+52) | ≥5 mm 无铜/无过孔/无螺钉焊盘；柔板从 X≈±12 绕行 |
| 螺柱 1/2/3 | 焊盘按 M2；周围 keep-out 按结构支撑面 |
| 光学暗室 | TI LED/PD 下无高速数字穿行；ADPD 位 DNP |
| 声腔投影 | 大电流环路避开腔下敏感模拟 |
| 电池仓 (0,−55) | 簧片/座子回流强化；远离天线半平面 |

---

## 3. 关键网络布线优先级

| 优先级 | 网 | 规则 |
|---|---|---|
| P0 | `HORN_DRV` | 短、粗；回流不穿 RF 参考；禁与 `LED_RGB_DATA`/RF_WAKE 复用 |
| P0 | `LED_RGB_EN` → VLED 开关 | 开关近 bulk；Idle 可切断整岛 |
| P0 | `LED_RGB_DATA` | 出 SoC 串 22–33 Ω；单线电平按料号；CLK 单线方案 DNP |
| P1 | RF 匹配 | 按料册；差分/共面按天线类型 |
| P1 | `CO_SIG` / `OPT_DISC_ADC` | 模拟：护环或地屏蔽，远离灯数据沿 |
| P2 | I2C ADPD（EVT） | 与 TI 轨互斥装配 |
| P2 | SWD/UART | 测点出边 |

峰值墙：VSYS/VLED 各 ≥100–220 µF 低 ESR 就近；线宽按 **≥1 A** 余量（持续 600 mA / 脉冲 1200 mA）。

## 4. 与结构接口冻结点（布线不得擅改 XY）

螺柱 (+41.6,0)/(-20.8,+36)/(-20.8,-36)；天线馈 (0,+48)；窗 (0,+52)；灯环 R=58；BTN (0,-58)；电池 (0,-55)；接插件 (+35,0)。改动须再开叠板互检。
