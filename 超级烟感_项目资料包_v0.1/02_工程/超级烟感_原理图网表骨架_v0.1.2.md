# 超级烟感 · 原理图网表骨架 v0.1.2

**相对 v0.1.1**：灯驱改 **64×可寻址 RGB**（单线默认 / SPI 备）；对齐 ICD v0.1.4a、FSM v0.3。白壳主 SKU。  
**状态**：总线脚可进 ICD；绝对坐标仍 3–5 日冻（不下单）

## 1. 路径光总线（取代 I2C1 单色灯驱）
| 逻辑名 | SoC Pin（草案） | 网名 | 电气 | 备注 |
|---|---|---|---|---|
| LED_RGB_DATA | P2.06 | LED_RGB_DATA | 单线 DOUT / SPI MOSI | 可寻址协议；**禁**与 HORN/RF_WAKE 复用 |
| LED_RGB_CLK | P2.07 | LED_RGB_CLK | SPI SCK | **单线方案 DNP** |
| LED_RGB_EN | P2.08 | LED_RGB_EN | GPIO→负载开关 | 灯串 VLED 使能；**Idle 默认关** |
| LED_STATUS | P0.01 | LED_STATUS | GPIO/PWM 直驱 | 中心点；不经灯串 |

灯珠：环上 **64** 颗可寻址 RGB（细环）+ 底边线型可共用尾段或独立 4–8 颗（结构定）。级联顺序与开孔 ch0–63 地址表由结构/软件对齐。

VLED：VSYS 或 3V3 经 `LED_RGB_EN` 开关 + 大电容就近灯串；单线电平移位按料号。

## 2. 其余信号（继承 v0.1.1）
OPT_I2C_* / OPT_INT / OPT_DISC_ADC / OPT_RAIL_SEL / CO_SIG / CO_BIAS_EN / VBAT_SENSE / HORN_DRV / BTN_TEST_MUTE / COVER_DET / HW_FAULT / CONTAM_TP / SWD — 不变。  
**删除** v0.1.1 的 `LED_I2C_SCL/SDA`、`LED_DRV_INT`（单色 I2C 灯驱作废为默认）。

## 3. 硬路径
`HORN_DRV` + 报警红可用 RGB 段脉动，但 **≤50 ms** 判决→声光不经 Thread；`LED_RGB_EN` 在 Alarm 必须先置位再出帧。

## 4. 堆叠
电子栈 ≤28 mm；总厚 ≤45 mm；天线 ≥5 mm；电池侧置。RGB 灯珠贴环柔灯板/硬灯环，禁 Nest 大环面灌光 PCB。
