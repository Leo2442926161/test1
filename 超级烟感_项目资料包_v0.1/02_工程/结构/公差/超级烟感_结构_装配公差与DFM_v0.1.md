## 1. 装配说明（爆炸顺序）

天花侧为底座，房间侧为白壳外观面。坐标系同草排：板心原点，+Z 朝房间。

| 顺序 | 零件 | EVT 做法 |
|---|---|---|
| 1 | 主 PCB | B-TI：装 TI 分立，ADPD 焊盘空。A-ADPD 仅 EVT 对测，不送 Listing。共型烟腔，只换光学子件 |
| 2 | 三颗 M2 螺柱 | 只认草排三点：(41.6, 0)、(−20.8, 36.0)、(−20.8, −36.0)。螺柱不进天线窗 |
| 3 | 压电 | 装入 (0,−40) 独立腔，深 9.0，垫圈封死。腔不与烟迷宫、灯井、路径光腔相通 |
| 4 | 柔灯环 | 基准缺口朝 **+X = ch0**。接插件走硬件点 (+35, 0)。铜皮绕开 (0,+52) 天线窗 |
| 5 | 底边导光条 | 单独一件，弦 Y=−62，`PATH0–5`。与细环之间留不透光肋 |
| 6 | 光学迷宫 + CO 气窗 | 进烟在左右裙边；CO 窗口约 (60, 22)；两者都不对着出声缝 |
| 7 | 白壳 | 细环 64 缝 + 中心 Ø2.4 导光柱。壳是白的，缝是窄的 |
| 8 | 电池仓盖 | 侧壁，电芯轴向沿切向。盖上后 `COVER_DET` (−40,−20) 闭合。打开盖不抬起触点 |
| 9 | `BTN_TEST_MUTE` | 键帽在裙边 (0,−66)，推杆在 Z 0..+4 到达对齐点 (0,−58)。不穿 ch48 井 |
| 10 | 拧转底座 | 顺时针锁到天花板。本壳 **没有** 有线互连孔 |

无线级联不增加任何壳体开口。

## 2. 关键公差

草排级：下表未写出更紧数字的尺寸，一律 **±0.5 mm**。右边「后续模具目标」来自结构概念页，**本 EVT 不按那个验收**。

| 尺寸 | EVT 草排 | 后续模具目标（未执行） |
|---|---|---|
| 灯环中心 R、ch 坐标、螺柱、天线窗、键对齐点 | ±0.5 | 灯缝位置另出检具 |
| 段间遮光井壁厚 0.8、井必须拉通 | ±0.5，但井不许破 | 串光为功能不合格，不靠放宽公差 |
| 天线净空柱高度 | **≥5.0**，只许更大 | 金属进入该柱即退回 |
| 声腔深度 | 9.0，允许 8–10 | 实验室声压另测，此处不写 dB 合格线 |
| 总厚 | 42.0，不得越过 45 | 挑战 ≤40，本堆叠未进 |
| 电子栈 | 目标 27，不得越过 28 | 含灯环叠高 |
| 键行程 | 0.6，须落在 0.4–0.8 | 手感段落由 ID 定 |
| 主视面面差、底座缝 | 草排不卡 0.15 / 0.3 | 概念页目标，等 ID 定稿 |

外壳外径 Ø135、PCB 可用 Ø112 与硬件草排一致，±0.5。

## 3. DFM

| 项 | 要求 |
|---|---|
| 材料 | 白壳：PC 或 PC+ABS，浅色。阻燃等级只写「候选 V-0」，无证书就不写已符合。导光：透明 PC。遮光井：不透光料，二射或嵌件，不许靠白壳自己挡光 |
| 壁厚 | 名义 1.8，局部不薄于 1.2。电池门单独成件，避免深腔缩痕把整壳做厚 |
| 拔模 | 外观件约 1°。灯井沿出光方向拔，井壁不能在中段变薄到透光 |
| 细环 | 出光缝 2.2×1.4，节距约 5.7。禁止把 64 段合成一条宽光带，禁止大环面灌光 |
| 天线 | 窗口只留塑料。禁导电漆、禁金属螺钉、禁电池负极片、禁蜂鸣铁壳进入净空柱。柔板地从窗两侧绕 |
| 电池 | 塑料托或开槽金属托；托若金属，必须停在 −Y 侧壁，距天线窗 ≥5。极性筋 + 丝印。反插不可到底 |
| 开盖不断电 | 门打开时弹簧仍压住电芯。`COVER_DET` 在电芯被抽出之前切换。半开状态给产测留探针 |
| 声腔 | 独立 8–10 mm。出声缝朝房间，避开进烟与路径光。蜂鸣铁壳不靠近天线 |
| 光学 | 同一腔两套焊盘。量产只贴 TI。ADPD 空贴。定位柱防迷宫转 180° |
| 互连 | 模具上不要做穿线孔镶件。Phase-1 电池壳与将来硬线底座如果要分件，那是另一件底座，不是在本壳上打孔 |
| 分色 | 美欧阻燃料若分料号，共模仁换镶件，料号不要混。ID 轮廓仍共型 |

## 4. DFA（EVT 工位）

1. 扫码区分 B-TI / A-ADPD，防止 ADPD 板流入 Listing 箱。
2. 螺柱用治具对三点，不靠目测「均布」。
3. 柔板缺口朝 +X 才能插入接插件护套；插反则 ch0 不在右侧。
4. 导光件最后装，戴手套，来料保护膜在锁壳前才撕。
5. 电池门与键帽是两件。先确认推杆不顶进灯井，再装门。
6. 拧底座：顺时针到位有止挡；逆时针可拆。EVT 用螺钉固定 PCB，便于返工；量产卡扣以后再说。
7. 禁止把有线互连线束「临时」从出声缝或进烟口带出。

目标节拍不在本版承诺。

## 5. 声光开孔验证（支撑 EVT，不代替实验室）

| 检查 | 通过 |
|---|---|
| ch0 单亮 | 亮在 +X，地址表坐标 (58, 0) |
| ch16 单亮 | 亮在 +Y 细缝；天线窗内无金属 |
| ch48 单亮 | 6 点细缝亮；键帽与 PATH 不亮 |
| ch0→63 | 正视逆时针走完，邻井不串光 |
| `LED_STATUS` | 环全灭时中心点仍可单独亮 |
| PATH | 环全灭时底边弦可单独流动 |
| 出声 | 缝在 (±10,−48)；烟从左右进烟口灌入时，声腔垫圈不进烟 |
| 天线 | 馈点 (0,+48) 向上 5 mm 量具无金属 |
| 开盖 | 门开、电芯仍在，板仍上电，`COVER_DET` 状态变了 |
| 键 | 安装态（拧在底座上）单手按到 `BTN_TEST_MUTE`，行程约 0.6 |
| 互连孔 | 目视无穿线孔 / 敲落孔 |

全环满白只用工装外电。
