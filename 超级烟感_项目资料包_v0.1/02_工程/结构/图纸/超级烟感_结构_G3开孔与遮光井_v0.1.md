## 1. 外观禁止项

主视面是白盘。发光只允许：64 条细缝、中心一个点、底边一条短路径。

| 禁止 | 本图的做法 |
|---|---|
| Nest 大环面 / 整圈发光带 | 每段缝只有 **2.2 × 1.4**。节距约 5.69，中间是不透光肋 |
| 64 段合成一条宽光槽 | 段间遮光井拉通，邻段单点时不得借光 |
| 灯井串进烟腔或声腔 | 井壁封闭，见 §3 |
| 底边路径占用 ch 号 | PATH0–5 另腔，不进 ch0–63 |
| 有线互连开孔 | 不开穿线孔、敲落孔、端子窗 |
| 中心大键 | (0,0) 只出状态光，Ø2.4 |

几何占比（只说明开孔面积，不是照度）：盘面约 π·67.5² ≈ 1.43×10⁴ mm²。64 条缝约 197 mm²，加上中心点与底边路径，发光开口不到盘面的 2%。打样若出现连续亮环，就是缝被铣通了，按不合格退回。

## 2. 细环 64 缝

| 项 | 值 |
|---|---|
| 光学中心半径 | **R = 58** |
| ch0 | (58.00, 0.00)，+X |
| 方向 | 正视外观面 **逆时针**；α = k × 5.625° |
| 公式 | X = 58·cos α，Y = 58·sin α |
| 缝 | 切向 **2.2** × 径向 **1.4**（径向从 57.3 到 58.7） |
| 节距 | 2π·58/64 ≈ **5.69** |
| 不透光肋 | 节距减去缝宽，约 **3.5** |
| 出光面 | Z = +26，可沉 0.3，不得凸成一圈光环 |
| 柔板缺口 | 只能朝 +X，对准 ch0 |

抽查点（其余见地址表）：

| ch | α | X | Y | 位置 |
|---:|---:|---:|---:|---|
| 0 | 0 | 58.00 | 0.00 | +X，装配基准 |
| 16 | 90 | 0.00 | 58.00 | +Y，贴天线窗边缘，井内只许透明塑料 |
| 32 | 180 | −58.00 | 0.00 | −X |
| 48 | 270 | 0.00 | −58.00 | −Y。与按键同 XY、不同 Z |

```
白壳外表面 Z=+26
  缝 1.4 径向
  ┌─┐  ┌─┐  ┌─┐
  │ │肋│ │肋│ │     ← 肋约 3.5，不透光
  └─┘  └─┘  └─┘
     遮光井壁 0.8，Z +6 → +26 拉通
        灯珠约 Z=+3，R=58
```

## 3. 段间遮光井

|---|---|

ch48 与按键：井在 Z +6 以上；`BTN_TEST_MUTE` 推杆只在 Z 0..+4。对图时从缝里看，不应看见推杆。
