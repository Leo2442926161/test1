## 1. 约定

| 项 | 锁定 |
|---|---|
| 坐标系 | 与硬件草排相同：板心 = 壳体圆心为原点；**mm**；正视外观面，+X 右，+Y 上 |
| 角 α | 自 **+X** 起、正视外观面 **逆时针** 为正（与数学角一致）。硬件草排只写「角 0° @ (58, 0)」；本表用逆时针把该句算成唯一坐标 |
| ch0 | α = 0°，光学中心 **(58.00, 0.00)**，3 点钟 |
| 步进 | 5.625°；ch_k 的 α = k × 5.625° |
| 半径 | 光学中心 **R = 58.00**（柔灯环，在 Ø112 PCB 可用圆之外） |
| 公式 | X = 58·cos α，Y = 58·sin α |
| 表内小数 | 计算到 0.01 mm，便于对表；**制造公差仍是草排 ±0.5 mm**，不是 0.01 mm 的模具精度 |
| 出光缝 | 每段切向开口 2.2 × 径向 1.4；段间不透光肋约 3.5（节距 5.69）。细缝，不是大环面 |
| 遮光井 | 每段独立井，井壁 0.8，从灯珠到出光缝拉通，禁止邻段串光，禁止串进光学腔 |
| 不在本表 | 底边路径光 `PATH0–PATH5`、中心 `LED_STATUS`。它们不占用 ch0–63 |

软件环扫方向：ch 递增 = 正视外观面逆时针。固件若按顺时针播放，须在映射层取反，不得改开孔号。

## 3. 与 ID 开孔的对齐点

| 标记 | 坐标 | 用途 |
|---|---|---|
| 柔板基准缺口 | 对准 ch0 (58.00, 0.00) | 装配防呆：缺口只能朝 +X |
| ch16 | (0.00, 58.00) | 12 点，贴天线窗边缘；此段导光只允许介质，窗内禁止铜皮/螺钉 |
| ch48 | (0.00, −58.00) | 6 点细缝。与 `BTN_TEST_MUTE` 对齐点同 XY，**不同 Z**（见草排）。出光缝不被键帽挡住 |
| LED_STATUS | (0.00, 0.00) | 中心状态点，不进灯串，不进本表通道号 |

## 4. EVT 对光步骤

1. 柔板缺口朝 +X，点亮仅 ch0：出光应在右侧，不得亮在 12 点。
2. 只点 ch16：12 点细缝亮，天线窗塑料内无金属反光件。
3. 只点 ch48：6 点细缝亮，键帽与底边路径光保持熄灭。
4. 顺表 ch0→ch63 逐段：正视逆时针走一圈，邻段不亮。
5. 全环满白只允许工装外电（SED L6），不在电池上做。
