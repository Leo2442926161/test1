## 锁定几何

| 项 | 锁定 |
|---|---|
| 外径 | Ø135 |
| 总厚 | 42（Z=+26 到 Z=−16） |
| 螺柱 | R=41.6；(41.6, 0) / (−20.8, +36.026) / (−20.8, −36.026)。不是 R=48 |
| 灯环 | R=58，**64** 个 Ø1.4 柱孔，ch0–63。不是 12 点，不是 Nest 大环面 |
| 天线窗 | (0, +52)，开口 18×12；净空柱 Ø20，Z 1.8→6.8 |

草排 Markdown 把螺柱 Y 写成 ±36.0。壳体模型用 36.026。差 0.026 mm，在 ±0.5 里。窗开到 Y=+58，ch15–ch17 的孔和窗在顶壁上相接；64 个孔都在。窗缘到侧壁内表面约 7.7 mm（≥5）。白壳薄壁，主壁 1.8。
