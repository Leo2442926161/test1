## 1. 拔模、壁厚、分型

| 项 | EVT / 开模准备 |
|---|---|
| 主壁 | 名义 **1.8**，局部不薄于 **1.2** |
| 拔模 | 外观侧约 **1°**。灯井沿出光方向拔，中段不得薄到透光 |
| 分型 | 放在裙边，约 Z=+8 以下。**不要**横过白盘，也不要从 64 条细缝中间分型 |
| 细缝 | 2.2×1.4 用嵌件或滑块做出。禁止把 64 段铣成一条槽再靠油墨挡光 |
| 遮光井壁 | **0.8**。破壁即串光，DFM 不许把壁厚让到 0 |
| 缩痕 | 电池门单独成件（ME-07），避免为了侧壁仓把整壳做成深腔厚饼 |
| 总厚 | 保持 **42**。不得靠加高底座去“好成型”而超过 45；也不要把 42 改写成挑战值 40 |
| 表面 | 白色。阻燃只写候选，见 §4，没有证书就不写 V-0 已过 |

螺柱根部圆角约 0.4，柱身内孔按 M2 自攻前孔径，外径约 4.5。三颗柱的支撑面在 Z=−1。柱位只允许锁定的三点，天线窗圆柱（中心 (0,+52)，径约 20，Z 1.8→6.8）里**不准**再长出工艺柱或镶针。

## 3. DFM 风险（针对本堆叠）

| # | 风险 | 处理 |
|---|---|---|
| 1 | 可换电侧壁与总厚 42 抢空间 | 电芯放在 Z +6..+23；声腔放在 Z −7..+2。不把两颗 CR123A 叠在 Z 上 |
| 2 | 6 点钟 XY 重叠（声腔、电池、键、ch48） | 已用 Z 错开。改模时不许把推杆抬进 Z≥+6 的灯井 |
| 3 | ch16 贴天线窗 | 该段只走透明塑料；铜皮从 X≈±12 绕行；窗内无导电漆 |
| 4 | 遮光井 0.8 壁出模拉断 | 嵌件优先于纯白壳挡光。首件做单段点亮 |
| 5 | 烟腔与灯井串光 | 迷宫包络停在 R 远小于 58 的区域；井不开向腔 |
| 6 | 有人在底座上加穿线孔“方便以后硬线” | **一期禁止**。硬线如果要做，是另一件底座，不是本壳打孔 |
| 7 | 墙装支架被打进同一套模 | **一期仅顶装**。不放墙装镶件 |
| 8 | ADPD 与 TI 同时贴 | Listing 板 ADPD 空贴。治具用空贴检测，不要靠目视颜色 |

## 4. DFA（EVT 工位）

顺序与装配图一致。这里只写会装错的步骤。

1. 扫码 **B-TI**。ADPD 焊盘必须空。A-ADPD 只进 EVT 对测箱，不进 Listing 箱。  
2. 三颗 M2 用坐标治具，不靠“看起来均布”。治具孔就是 (41.6, 0) / (−20.8, 36) / (−20.8, −36)。  
3. 柔灯环缺口朝 **+X** 才能进接插件护套 (+35, 0)。插反则 ch0 不在右侧，整灯环报废方向。  
4. 声腔垫圈先压进 (0,−40)，再锁壳。垫圈漏气会和进烟口串腔。  
5. 导光嵌件最后装，戴手套。保护膜在锁白壳前撕。  
6. 先装推杆（Z 0..+4），确认不进 ch48 井，再装电池门。  
7. 电池门极性筋：反插电芯不能到底。门打开时弹簧仍压住电芯。  
8. `COVER_DET` (−40,−20) 在电芯能被抽出之前必须已经切换。  
9. 底座顺时针止挡后，出声缝 (±10,−48) 仍朝房间，没有被天花堵住。  
10. 全壳目视：无穿线孔。没有墙装支架随箱。

EVT 用螺钉固定 PCB，方便返工。量产卡扣不在本版。
