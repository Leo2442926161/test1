## 2. 缺口

| ID | 缺口 | 现状 | 负责人 | 跟踪 |
|---|---|---|---|---|
| SW-01 | nRF54L15 可烧录镜像 | 无 `.hex` / `.elf`。MANIFEST `ncs_board_build=false`。无 NCS 工程、分区、overlay | 软件 | [#15](https://github.com/Leo2442926161/test1/issues/15) 未关闭。验收勾选含镜像 + SHA256 |
| SW-02 | 样机回读同一套钩子 | JSON 只在宿主 stdout。无 UART/RTT 产测口 | 软件 | [#15](https://github.com/Leo2442926161/test1/issues/15)：`hush_*` / `alarm_relay_*` / `relay_enable` |
| SW-03 | EVT 电流样，`TC-CASCADE-PWR-01` | 宿主套件 **SKIP**，原文 `EVT hardware Vbat/current; not run and no result claimed`。`fw_ux.c` 用 45 mA/段、蜂鸣 120 mA、级联 TX 40 mA 驱动钳位 | 软件交样；测试出通过/退回单 | [#15](https://github.com/Leo2442926161/test1/issues/15)。规程文档在已关闭的 [#13](https://github.com/Leo2442926161/test1/issues/13)，表内实测数仍空 |
| SW-04 | Matter 协议栈 | 仅 `notify_only`、会话布尔、`matter_notify_attempts/sent`。无配网、集群、订阅 | 软件 | **待补**。没有单独的 Matter 栈 Issue。实机钩子仍归 #15，栈本身不在 #15 的三条勾选里 |
| SW-05 | 手机 App | 仓库无 App 工程 | 软件 | **待补**。无对应 Issue |
| SW-06 | OTA | 无 MCUboot、无槽位、无版本比较、无「OTA 拒升」函数。L7 减亮只认测试注入的 `rf` 标志 | 软件 | **待补**。无对应 Issue |
| SW-07 | `relay_enable` 持久化 | 节点内存布尔，默认 true（`TC-NVS-RELAY-DEFAULT`） | 软件 | 移植时进 Zephyr settings。随 [#15](https://github.com/Leo2442926161/test1/issues/15) 的板级工程 |
| SW-08 | 烟/CO/光学驱动 | 报警由 `fw_set_alarm` 或 CLI `smoke`/`co` 注入。无 ADPD、无 TGS5141、无 `OPT_RAIL_SEL` | 软件（驱动）依赖硬件网表 | **待补**。硬件文件不在本目录写 |
| SW-09 | 64 段 RGB 帧与单线时序 | `applied_segments` 是钳位后的个数。`fw_ux_push_frame` 只检查 `LED_RGB_EN`。无像素缓冲，无 P2.06 波形 | 软件 | **待补** |
| SW-10 | FSM 未进枚举的模式 | 无 `Spin_Short`、`ClearSweep`。`PATH_GUIDE` 与环扫共用窗/亮度上限，无独立底边灯 | 软件 | **待补**。文案在 FSM v0.3 |
| SW-11 | 语音播放 | `voice_enable` 可写。无关声光限额（L8）。无短句音频 | 软件 | **待补**。文案：[语音短句 v0.1.1](超级烟感_语音短句_v0.1.1.md) |
| SW-12 | 报警解除的级联帧 | `fw_clear_alarm` 只清本机。已 follow 的对端不会因此关闭 | 软件 | **待补**。产品若要「解除也跟报」，需另定帧；当前 ICD 钩子包没有这条测试 |
| SW-13 | 低电、仓盖、故障传感、确认窗 20 s | 模型无这些状态。`FW_UX_PULSE_FAULT` 可以被 CLI 直接设入，没有故障判决器 | 软件 | **待补** |
| SW-14 | 实验室通过记录 | 软件树不存放 UL/EN 证书或预扫通过页 | 认证 / 测试 | 限值与排期在 [#9](https://github.com/Leo2442926161/test1/issues/9)。软件侧只保持 `claims.txt` 里的否定项（不声称有线多站互联） |
