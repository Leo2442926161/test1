## 3. 整机验收 · TC-SYS-*（本册正文）

**前置**：固件对齐 ICD v0.1.7；钩子 `hush_*` / `alarm_relay_*` / `ux_light_*` / `relay_enable`；示波或逻辑分析仪可测 HORN/LED_EN；≥1 台 DUT（级联相关仍用分册双机）。

### 3.1 自检与硬路径

#### TC-SYS-01 · 上电自检 SelfTest — **P0 / G3**
**步骤**
1. 断电 → 装妥电池 → 上电。
2. 观察自检声光短反馈（规格：可听可辨；非 Nest 剧本）。
3. 回读无 `HardwareFault`；串口/Matter 无故障码。

**通过**：自检完成；进入 Idle 且 `LED_RGB_EN=0`（L4）；传感器任务运行。  
**退回**：无自检；卡死；误报 P0。

#### TC-SYS-02 · 硬路径 ≤50 ms — **P0 / G3**
**步骤**
1. 工装注入烟 P0 判决边沿；探针 `HORN_DRV` 与 `LED_RGB_EN`。
2. 测判决标志 → 蜂鸣/EN 置位延迟。

**通过**：≤50 ms；Alarm 先 `LED_RGB_EN=1` 再出帧；路径**不经** Thread/Matter。  
**退回**：>50 ms；或硬路径依赖网络。

#### TC-SYS-03 / TC-SYS-04 · 断网本地声光（烟 / CO）— **P0 / G3**
**步骤**：断互联网与 Border；分别触发烟 P0、CO P0。  
**通过**：本机完整声光；音型可区分（烟三脉冲意图 / CO 四脉冲意图——绝对模式以实验室为准，内部证独立性）。  
**退回**：无声光；或依赖 App。

#### TC-SYS-13 · Fault / Contamination 指示 — **P1 / G3**
**步骤**：注入 `HW_FAULT_SNS` / 污染测点。  
**通过**：Pulse_Fault 可区分；非烟/CO 疏散音型。  
**退回**：与火警不可分。

### 3.2 电源与仓盖

#### TC-SYS-05 · 低电 BatteryAlert — **P0 / G3**
**步骤**：工装拉低 `VBAT_SENSE` 至规格告警阈（以 ICD/寿命表阈值为准，未冻则记「工程阈」并标待实验室）。  
**通过**：低电指示+可听提示；**不**关闭烟/CO 探测；危急仍可 P0。  
**退回**：低电后无法报警；或无指示。

#### TC-SYS-06 · COVER_DET — **P0 / G3**
**步骤**：开盖换电；确认开盖不断电逻辑与盖检测事件。  
**通过**：开盖可换电；`COVER_DET` 事件可回读；盖好后恢复正常 Idle。  
**退回**：开盖掉电丢配置；或无盖检测。

#### TC-SYS-15 · 换电后自检 — **P1 / G3**
**步骤**：换电上电跑 TC-SYS-01。  
**通过**：同 SYS-01。

### 3.3 路径光与语音

#### TC-SYS-07 · 夜间路径光暗室 ≥4 m — **P0 / G3**
**步骤**：暗室触发 PathGuide/RingSweep；观测距离。  
**通过**：≤0.5 s 起亮；单向流动；暗室可见 ≥4 m；守 L1–L3。  
**退回**：乱闪；或破 SED 窗/亮度。

#### TC-SYS-08 · 三套告警光语 — **P0 / G3**
**步骤**：分别进 Smoke / CO / Fault。  
**通过**：色+节奏可区分；危急盖过夜间路径。  
**退回**：三者不可辨；或 Nest 大环面/绿闪 Nightly 照搬。

#### TC-SYS-09 · 语音可关 ≠ 声光可关 — **P0 / G3**
**步骤**：`voice_enable=0`；触发烟 P0；尝试用户路径关声光。  
**通过**：无语音；声光仍满；无永久关声光入口（与 TC-HUSH-04 一致）。  
**退回**：关语音导致无声光；或存在永久关报警。

#### TC-SYS-10 · 语音不阻塞硬路径 — **P0 / G3**
**步骤**：`voice_enable=1`；测硬路径延迟同 SYS-02。  
**通过**：仍 ≤50 ms。  
**退回**：播报阻塞声光。

### 3.4 连接与轨识

#### TC-SYS-11 · OTA 拒升 Alarm — **P0 / G3**
**步骤**：P0 报警中请求 OTA。  
**通过**：拒绝升级；声光不中断；有失败码。  
**退回**：OTA 中断报警。

#### TC-SYS-12 · 光学轨识 — **P1 / G3**
**步骤**：读 `OPT_RAIL_SEL`；确认 TI/ADPD 互斥装配识别。  
**通过**：与 BOM 一致。  

#### TC-SYS-14 · Matter 状态事件 — **P1 / G3**
**步骤**：配对；触发报警；确认 Matter 通知；再断 Matter 跑级联分册 TC-MATTER-BOUND-01。  
**通过**：有状态/事件；**不替代**本地级联。
