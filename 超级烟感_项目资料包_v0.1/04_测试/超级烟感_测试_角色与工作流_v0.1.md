# 超级烟感 · 测试 / DQE · 角色与工作流 v0.1

**日期**：2026-10-22（Asia/Shanghai）  
**用途**：供项目管理汇总人员职责。本页只定角色、边界与工作流；不新增测项，不填实测。

---

## 1. 角色

测试与品质监督（含 DQE）。主导 **G3 技术放行**。

---

## 2. 职责

- 测试计划、自动化 / 产测、回归与可靠性。
- **DQE**：设计阶段的可靠性、可测性、失效预防。
- 试产 / 量产质量门禁与放行意见；失效分析协同。

规程、验收单、报告与证据的现行正文见同目录 [`README.md`](README.md)。

---

## 3. 不做

- 不改产品范围与设计方案。
- 不代签硬件、软件、结构方案。
- 不编造 mA、声压、实验室限值。实机格保持空白，直到有样机与镜像。
- 不叠总清扫代理；不碰 `超级烟感_结构_*` 与硬件正文。

---

## 4. 路径归属

只拥有 `04_测试/{测项,验收单,报告,证据}`。

测试正文不在 `02_工程/`。该处 stub 已清，不恢复一行转发。

## 5. 工作流

### 输入

| 来源 | 内容 |
|---|---|
| 软件 | [Issue #15](https://github.com/Leo2442926161/test1/issues/15)：nRF 烧录镜像 + EVT 电流 |
| 硬件 | 样机、测点 |
| 结构 | 坐标（只读） |
| 已有宿主包 | `fw-hush-relay-0.1.0-evt` 钩子验收为**有条件通过**（[`验收单/超级烟感_G3钩子验收_fw-hush-relay-0.1.0-evt_v0.1.md`](验收单/超级烟感_G3钩子验收_fw-hush-relay-0.1.0-evt_v0.1.md)）。这不等于实机 |

### 执行

Issue #15 到位（真实烧录镜像 + EVT 电流样）之后，冲实机 **P0 / PWR / SED**。结论写入 `验收单/` 与 `报告/`。镜像或电流未到，不把宿主 sim 抄成实机 Pass。

### 输出

放行意见回写项目管理门禁看板。日程、脊骨、禁双开跟项目管理。

## 6. 对接

| 对象 | 测试侧 |
|---|---|
| 硬件 | 收样机与测点；不代签硬件方案 |
| 软件 | 收 #15 镜像，回读钩子；不代签软件方案 |
| 结构 | 读坐标；不改 `超级烟感_结构_*` |
| 设计制造 | 试产 / 量产质量门禁与失效分析协同 |
| 增长 | 声称与文案抽检结论可供引用；不改产品范围 |
| 项目管理 | 收放行意见进门禁看板；日程、脊骨、禁双开由项目管理定 |

**G3 技术结论归测试。节奏归项目管理。**
