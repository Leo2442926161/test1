# 互联（级联）与 Hush · 产品范围锁定 v0.1.1

日期：2026-10-22 Asia/Shanghai  
相对 v0.1：按 Leo/Heiman 细则——**Hush 仅烟、默认 9 min、CO 禁止静音**  
状态：**产品已锁**（非法律意见；UL/EN 精确限值待实验室）

---

## 1. Hush / 临时静音 — **一期必达**

| 项 | 锁定 |
|----|------|
| 适用范围 | **仅烟雾报警（烟-only）** 可 Hush |
| 时长 | 默认 **9 min** 自动恢复（落在原 8–10 目标内） |
| **CO** | **禁止用户静音**（无 Hush；危急路径始终可听） |
| 不可静音 | 声光报警不可被用户永久关闭；语音可关 ≠ 声光可关 |
| 恢复 | 超时自动恢复；危急升级/再探测可打断 Hush |
| 多机 | 本机 Hush **不压制**已级联他机的报警声 |
| 可测 | 烟：启动→声压降→9 min 恢复；CO：无 Hush 入口或拒绝；多机不压制 |
| Listing | temporary silence for smoke / hush；不写可静音 CO |

→ @软件：`MuteWindow` 仅挂烟；时长常量 9 min；CO 拒绝 hush  
→ @测试：烟 Hush / CO 禁静音 / 多机不压制 可复现步骤

---

## 2. 级联 / 互联 — **一期必达（无线同品牌）**

### 2.1 做

| 项 | 锁定 |
|----|------|
| 形态 | **无线本地级联**：一台烟或 CO **P0** → 已配对同品牌机 **同类型本地声光跟报** |
| 承载 | Thread / 自研安全报文；**离线仍可**（不依赖云/手机） |
| Matter | **仅状态/通知**，**不替代**本地级联 |
| 开关 | 用户可开/关「级联报警」 |
| Listing | interconnected / whole-home alerts（同品牌）；不写消防总线替代 |

### 2.2 不做

| 项 | 锁定 |
|----|------|
| 有线多站互连主轨 | **不做**（可延） |
| Matter = 消防级互联 | **禁止声称** |
| Nest Heads-Up /「烟雾在×房间」剧本 | **禁止照搬** |
