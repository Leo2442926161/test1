## 1. 路径光（自研）— 主方案锁定

| 项 | 规格 |
|----|------|
| 主形态 | **细环（≤1 圈窄导光）+ 线型/分段路径光条**（正视/侧视/夜间态按 ID 板） |
| 备选 | 2–4 离散状态点（结构已预留；主轨仍为细环+线型） |
| 禁止 | Nest 式大环面可识别造型；绿闪「Nightly Promise」类公开节奏照搬 |
| 日常 | 待机近乎熄灭或极低占空；用户可关「常亮」 |
| 告警 | 烟 / CO / 故障：**色或闪烁模式**区分（色表软件定；色盲辅以声） |
| 路径指引 | 告警或夜间：沿线型导光**单向流动或逐段点亮**（自研时序表，软件定稿） |
| 可测 | 暗室可见距离 ≥3 m；待机→路径光功耗增量记入硬件账 |

## 2. 语音（自研）

| 项 | 规格 |
|----|------|
| 语言 | EX：EN 主；CN：中文 |
| 结构 | `[事件] + [建议动作]`，可选用户自命名 `[位置]` |
| 示例方向（须重写定稿） | Smoke detected. Leave the room. / CO detected. Move to fresh air. / Low battery. Replace batteries. |
| 禁止 | Heads-Up 预告剧本照搬；公开 Nest「烟雾在×房间」句式复刻 |
| 可关 | 语音可关；**声光报警不可关** |
| 可测 | 1 m 清晰可懂；Alarm 硬路径不因语音延迟 >50 ms |
