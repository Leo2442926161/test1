# PRD-超级烟感-v0.1 大纲

> **正式版见 `PRD-v0.1_正式版.md`（本大纲仅作索引；条文以正式版为准）。**
> 大纲锁定结构；完整条文在 G2 前展开。禁止据此开详细设计/开模。
> 修订：2026-10-22 Asia/Shanghai — Nest 对标必达 + **IP/体验自研约束**（Leo via Heiman）。

1. **目标与非目标** — 认证级 Smoke+CO + 可测抗误报 + Matter/Thread，$79–$99，美欧首发；外观与关键体验**目标**对标并压过 Nest Protect 2 档体验，但**对标≠照搬**。非目标：消防级互联替代、米家硬刚、无证贴牌、无法证伪的「更好」口号、**复制 Nest 专利/可识别外观与交互**。
2. **用户与场景** — Nest 替换/传统升级；厨房滋扰、多机定位、断网仍安全、夜间路径指引。
3. **必达 / 应达 / 可延**
   - **必达**
     - 探测：Smoke+CO；抗误报可测（双波段/多传感）。
     - 互联：Matter/Thread + 断网仍本地报警。
     - 外观/人机：薄型与拧转底座体验不低于竞品标杆；轮廓与质感目标优于 Nest 停产款（ID 评审）——**须自研造型语言**，禁止可识别抄袭 Nest 大环面等特征。
     - 续航可验证；可换电优先对照；合规美欧同步（含 UKCA）；本地安全不依赖云。
   - **应达（体验目标，非第四卖点）**
     - **路径光 / 光效**：自研细环或状态点光语（已定方向）；实现「夜间路径指引」体验目标。
     - **语音 / 位置提示**：自研状态机与文案剧本。
     - **IP 红线**（工程规避，非法律意见）：禁 Nest 大环面光语与可识别「Nightly Promise」绿闪节奏照搬；禁复刻 Heads-Up/「烟雾在×房间」类句式与剧本；Matter 仅状态/通知、不做专有语音位置互联卖点；测试对照只记事实；Listing **不点名 Nest**。详件见 `体验与IP约束_路径光语音_2026-10-22.md`。
     - 蒸汽/烹饪滋扰抑制可测；OTA。
   - **可延**：国内 CO、米家、完整多房间消防互联。
4. **卖点与证明（仍 ≤3）** — ①抗误报可测 ②Smoke+CO ③Matter/Thread。路径光/语音不上主卖点面。
5. **软硬件结构选项** — 传感/无线/电源/共模分模；光路 EVT 双轨（TI 量产默认 / ADPD 旗舰备选）。
6. **合规与分 SKU** — SKU-EX（UKCA，EN+DE/FR）；SKU-CN（3C，一期默认无 CO）。
7. **成功指标（90 天）** — 误报/续航差评、Matter 配对、毛利线；Nest 对照仅内部事实数据。
8. **文档与追溯** — 市场产品交付归档于 `01_市场产品/`（版本号为准）；代码走 git（工程岗）。
9. **开放问题** — 认证主路径；CO 保修与 OEM 价；路径光/语音自研规格量化（市场+软件+测试）。


### 外观锁定（2026-10-22）
- 主外观：浅色薄盘（白）；低剖面对标 Nest「更好看」目标
- 路径光：细环 64 分段 + 中心状态点 + 底边线型；禁 Nest 大环面

### 互联与 Hush（2026-10-22 锁定 · v0.1.1）
- **Hush**：一期必达；**仅烟**；默认 **9 min** 自动恢复；**CO 禁止静音**；多机不压他机。详：`互联与Hush_产品范围锁定_v0.1.md`（文内 v0.1.1）
- **级联**：一期必达——同品牌**无线本地**级联跟报（离线仍可）；Matter=状态通知不替代；**无有线互连主轨**；禁 Nest Heads-Up/房间名剧本。
