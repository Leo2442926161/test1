## 1. 路径光（自研）

| 项 | 规格 |
|----|------|
| 形态 | **细环 ≤1 圈窄导光** 或 **2–4 个离散状态点**（二选一主方案，ID 定稿）；禁止大环面可识别造型 |
| 日常 | 待机可近乎熄灭或极低占空；用户可关「常亮」 |
| 告警 | 烟/CO/故障用**不同颜色或闪烁模式**区分（具体色表软件定，须色盲可辨辅以声） |
| 路径指引 | 告警或夜间触发时：指向出口方向的**单向流动/逐点点亮**（自研节奏，禁照搬 Nest 绿闪「Nightly Promise」类节奏） |
| 可测 | 暗室：可见距离 ≥3 m；告警态与待机功耗增量待硬件账 |

## 2. 语音（自研）

| 项 | 规格 |
|----|------|
| 语言 | EX：EN 主；包材语种另计。CN：中文 |
| 内容结构 | `[事件类型] + [建议动作]`，可选 `[位置标签]`（用户自命名房间，非预置 Nest 句式） |
| 示例方向（须重写定稿，勿直译 Nest） | “Smoke detected. Leave the room.” / “Carbon monoxide detected. Move to fresh air.” / “Low battery. Replace batteries.” |
| 禁止 | Heads-Up 式预告剧本照搬；「烟雾在×房间」公开 Nest 句式复刻 |
| 可关 | 语音可关，**声光报警不可关** |
| 可测 | 1 m 处清晰可懂；Alarm 态优先本地声，语音不得拖硬路径 ≤50 ms |
