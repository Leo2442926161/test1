## 1. 认证路径总览（流程）

### 1.1 美国

```
选型锁料 → 原理图/PCB/结构冻结 → 预合规（RF / 安规桌面）
  → NRTL（UL Solutions / Intertek·ETL 等）开案：UL 217 + UL 2034 组合
  → 型式试验（烟隧道 + CO 浓度/响应 + 电气/环境 + 误报抗扰）
  → FCC Part 15（有意辐射，可与另一家并行）
  → 初始工厂检查 → Listing / Authorization to Mark
  → 量产 Follow-up Service
```

| 项 | 说明 |
|---|---|
| 生命安全 | NRTL 按 **UL 217**（烟）+ **UL 2034**（CO）双测；组合机须**同时**符合（业界常见双 Listing Mark） |
| 射频 | **FCC 47 CFR Part 15**（Thread/BLE 等有意辐射，典型 Subpart C；整机需授权，模组预认证通常不够单独上市） |
| 安装规范 | **NFPA 72** 等为安装/规范引用，**不是**产品认证本身；影响说明书安装位置表述 |
| 州法提示 | 多州对住宅 CO 报警有安装要求（IRC 等）；产品侧仍以 UL 2034 Listing 为准——具体州清单销售前由市场补 |

### 1.2 欧盟

```
选型锁料 → 技术文件骨架
  → 烟：CPR（EU）305/2011 + EN 14604 → Notified Body（AVCP，常见 System 1）→ DoP + CE
  → CO：EN 50291-1（+ 软件控制时 EN 50271，见下表）测试报告
  → 无线：RED 2014/53/EU（射频/EMC/健康与安全评估）→ EU DoC
  → RoHS / REACH / WEEE 材料与注册义务
  → 技术文件存档 ≥10 年 → 上市
```

| 项 | 说明 |
|---|---|
| 烟感 | **EN 14604** 为协调标准，落入 **CPR**；需 **Declaration of Performance (DoP)** + CE；合格评定通常需 **Notified Body**（AVCP System **1** 为公开实践常见表述，**送检前与 NB 书面确认**） |
| CO | **EN 50291-1:2018**（+ AC:2021-01）；组合机与烟标准**双测** |
| 射频 | **RED 2014/53/EU**；2.4 GHz Thread 常用 **EN 300 328**；EMC 常用 **EN 301 489** 系列（以 OJEU 现行引用为准） |
| LVD / EMC 指令 | 纯电池机 **通常不落 LVD 电压范围**；有意发射设备的 EMC 要求主要由 **RED Art. 3(1)(b)** 覆盖，不必重复套一套独立 EMC 自声明路径——**以实验室判定为准** |
| RED Notified Body | 完整适用并引用 OJEU 协调标准时，Art. 3(2) 可用 Module A（无 NB）；**未完整适用协调标准**或涉及 Art. 3(3) 限制时需 Module B+C / H（**有 NB**）。送检前核对 OJEU + 网络安全条款适用性（如 EN 18031 族，**待核实对本产品是否强制**） |

### 1.3 建议送检顺序与可并行项

| 顺序 | 工作包 | 可否并行 | 备注 |
|---|---|---|---|
| 0 | 锁光学/CO 料号、网表、认证固件 profile | — | G2 仍卡 CO 实价/授权 |
| 1 | 预合规：RF 功率/杂散桌面 + 声压/时序自测 | 与样机制作并行 | EVT |
| 2a | UL 217 + UL 2034 正式（NRTL） | 与 2b / 2c 并行 | 主工期常 **4–8+ 月** |
| 2b | EN 14604（CPR/NB）+ EN 50291-1 | 与 2a 并行 | 主工期常 **4–8+ 月** |
| 2c | FCC Part 15 + RED | 与 2a/2b 并行 | 常 **4–8 周**（模组复用可缩短） |
| 3 | Thread Group + CSA Matter | 与安规并行，**不互替** | 互通资质 |
| 4 | 工厂检查 / FPC 持续符合 | 证书前后 | UL Follow-up；CPR FPC 监视 |

**Matter / Thread 认证 ≠ 生命安全认证**，不可替代 UL Listing 或 CPR/CE。
