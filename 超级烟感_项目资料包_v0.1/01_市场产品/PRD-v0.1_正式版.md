## 1. 目标与非目标

### 1.1 目标

- 认证级 **Smoke+CO**（出海旗舰 SKU-EX）+ **可测抗误报** + **Matter/Thread** 互通。
- 零售价带 **$79–$99**：主推 **$89** / 旗舰 **$99** / 促销底 **$79**；美欧同步首发（含 UKCA 规划）。
- 外观与关键体验**目标**对标并压过 Nest Protect 停产款体验档，但 **对标 ≠ 照搬**。
- 本地安全：**断网仍本地声光报警**；声光报警**不可被用户永久关闭**。
- 一期必达：**Hush（仅烟）** + **同品牌无线离线级联**（见 §3、范围锁 v0.1.1）。

### 1.2 非目标

| 非目标 | 说明 |
|--------|------|
| 消防级有线/总线互联替代 | 一期不做有线互连主轨；不声称替代消防系统 |
| 米家一手硬刚 | SKU-CN 不承诺米家一手对接 |
| 无证贴牌上架 | Listing **不上架**直至认证与 G2 条件满足 |
| 无法证伪的「更好」口号 | 对外禁止 better than Nest 类表述 |
| 复制 Nest 专利/可识别外观与交互 | 见 IP 红线 §3.2 |
| 国内一期默认带 CO | SKU-CN 一期默认无 CO（可二期） |

## 2. 用户与场景

| 用户/场景 | 产品应对 |
|-----------|----------|
| Nest 替换 / 传统烟感升级 | 薄盘外观、拧转底座体验、Matter 入生态 |
| 厨房烹饪滋扰 | 可测抗误报（双波段/多传感）；烟 Hush 9 min；安装距烹饪器具见 N-06 |
| 多机定位 / 整屋跟报 | 同品牌无线本地级联（离线仍可）；Matter 只做状态通知 |
| 断网仍安全 | 本地声光硬路径优先；不依赖云/手机 |
| 夜间路径指引 | 自研路径光（细环 64 段 RGB + 旋转/环扫）；语音可关 |
| 换电与维护 | 可换电 CR123A×2；COVER_DET；低电/故障可测 |

## 3. 必达 / 应达 / 可延

### 3.1 必达（一期）

| 域 | 要求 |
|----|------|
| 探测 | Smoke+CO（SKU-EX）；抗误报可测（双波段/多传感） |
| 互联 | Matter/Thread；**断网仍本地报警** |
| **Hush** | **仅烟雾**可临时静音；默认 **9 min** 自动恢复；**CO 禁止用户静音**；本机 Hush **不压制**已级联他机；入口 `BTN_TEST_MUTE` |
| **级联** | 同品牌**无线本地**级联：一台烟或 CO P0 → 已配对机**同类型本地声光跟报**；**离线仍可**；用户可关「级联报警」 |
| Matter 边界 | **仅状态/通知**；**不替代**本地级联；禁止声称 Matter=消防级互联 |
| 有线互连 | **无有线互连主轨**（一期不做） |
| 外观/人机 | 薄型+拧转底座体验不低于竞品标杆；**自研造型语言**；禁可识别抄袭 Nest 大环面等 |
| 续航/电源 | 续航可验证；可换电优先；合规美欧同步（含 UKCA 规划） |
| 安全边界 | 声光报警不可永久关闭；语音可关 ≠ 声光可关 |

详锁：`互联与Hush_产品范围锁定_v0.1.md`（文内 **v0.1.1**）。

### 3.2 应达（体验目标，**非第四卖点**）

| 项 | 要求 |
|----|------|
| **路径光** | 自研细环 **64 分段 RGB** + 中心状态点 + 底边线型；夜间路径 + 自研旋转/环扫；暗室可见 ≥4 m（体验规格 v0.3） |
| **语音** | 自研状态机与短句剧本；可关；危急不阻塞声光硬路径（延迟 ≤50 ms，工程契约） |
| **IP 红线**（工程规避，**非法律意见**） | 禁 Nest 大环面光语与可识别「Nightly Promise」绿闪节奏照搬；禁复刻 Heads-Up /「烟雾在×房间」类句式；Matter 不做专有语音位置互联卖点；测试对照只记事实；Listing **不点名 Nest** |
| 滋扰抑制 | 蒸汽/烹饪滋扰抑制可测 |
| OTA | 签名/策略按 ICD；报警态拒绝 OTA（工程） |

详件：`体验与IP约束_路径光语音_2026-10-22.md`、`路径光语音_自研体验规格_v0.3.md`。

### 3.3 可延

- 国内 SKU-CN 的 CO、米家对接
- 完整多房间消防级/有线互连
- 96 段灯环（仅成本过线后 Leo 再批；默认 64）
- ADPD 性能轨量产 Listing（当前仅 EVT，Listing 绑 TI）

## 5. 软硬件结构选项

| 域 | 锁定 / 默认 |
|----|-------------|
| 光学 | **EVT 双轨**：量产默认 **TI 分立双波段**；**ADPD** 为性能/旗舰 EVT 备选；Listing **只绑 B-TI** |
| 主控/无线 | **nRF54L15**（差分备注 nRF52840 / MG24）；Matter/Thread |
| CO | **TGS5141** 主（Figaro）；**NAP-508** 备；OEM 实价/授权 **待回**（G2 阻塞） |
| 电源 | CR123A×2 并联；可换电；`COVER_DET`；开盖不断电策略按工程 |
| 壳体/光语 | **白壳**浅色薄盘；**64 段 RGB** + 自研旋转/环扫；禁 Nest 大环面 |
| 外形草排 | 外壳外径 **Ø135**（结构草排 v0.1 锁定）；安装螺柱 **R=41.6×3**（3×120°；坐标 **(41.6, 0) / (−20.8, 36.0) / (−20.8, −36.0)**；对齐 N-06 v0.1.2 / `#5`） |
| 人机键 | **`BTN_TEST_MUTE` = Hush/自检**（Hush 策略仅烟；CO 固件拒绝） |
| 级联承载 | Thread / 自研安全报文；**无**有线 `INTERCONNECT` 脚 |
| 天线 | 结构天线窗净空 **≥5 mm**（产品侧约束） |
