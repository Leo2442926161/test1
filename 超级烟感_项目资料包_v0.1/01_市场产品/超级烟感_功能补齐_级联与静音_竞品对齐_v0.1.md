## A. 竞品常用功能清单

| 功能 | 竞品常见做法 | 本产品现状 | 建议 |
|---|---|---|---|
| **无线互联/级联** | Nest：Weave/802.15.4，一响全响、报房间，约 50 ft，不依赖 Wi‑Fi；First Alert：RF mesh ~75–100 ft，可报位置；Kidde：Wire‑Free / 硬线+桥，一响全响 | 原边界偏 Matter 通知；**产品已锁**同品牌无线本地级联（一期必达） | **必做**（一期） |
| **有线多站互连** | 传统 AC 红线互联；部分品牌无线桥接旧硬线网 | 认证主稿：不做消防级有线互连声称；网表无互联脚 | **不做**（一期；可延） |
| **Hush / 临时静音** | Nest：按钮/近距 App；危急烟过浓不可静；CO 紧急可静（其产品规则）；First Alert：烟≤15 min、CO≤4 min；Kidde Hush 约 7–10 min | ICD 有 `BTN_TEST_MUTE`、FSM `MuteHold`；**已锁**仅烟、默认 **9 min**、**CO 禁止 Hush** | **必做**（烟 Hush）；CO 静音 **不做** |
| **自检 / Test** | 单键 Test；部分 App 远程测；Nest 自动自检宣传 | 有按键与探针草案；固件未开仓 | **必做** |
| **低电提示** | 啁啾；部分可静低电啁啾数小时（如 First Alert≤8 h）；App 推送 | `VBAT_SENSE` / BatteryAlert 在 ICD | **必做** |
| **夜灯 / 路径光** | Nest Pathlight；本项目自研细环 RGB 追逐（非 Nest 大环） | FSM/路径光规格 v0.3、SED L1–L8 已收 | **必做**（已在做；守 SED） |
| **App / 手机通知** | 烟/CO/低电/离线/寿命；部分可 App Hush（近距） | Matter 状态/事件；本地声光优先 | **必做**（通知）；App 远程 Hush **可选**（若做须近距/本机确认，且服从 CO 禁） |
| **语音播报** | Nest/First Alert/Kidde 多有语音+位置 | 短句 v0.1.1；语音可关 | **必做**（可关）；禁照搬 Nest「烟雾在×房间」剧本 |
| **报警音型区分** | 烟 T3 / CO T4 等 | 认证与软件清单已列；实现未开仓 | **必做** |
| **Heads-Up 早期提醒** | Nest 黄灯早期提醒 | 产品锁定：**禁止照搬** Nest Heads-Up 剧本 | **不做**（一期） |
| **Matter / 智能家居** | 部分走自有云；Matter 渐多 | Matter=状态/事件，**不替代**本地级联 | **必做**（通知边界）；**禁止**声称=消防互联 |
| **寿命终止 EOL** | 啁啾/语音/App | 待 PRD 能力层补一句 | **必做**（文案+测项后续） |
| **IAQ / TVOC 等扩展** | 部分 Kidde 智能款 | 非本品主卖点 | **可选/不做**（一期不做） |

### 建议写入 PRD / 能力清单的一期必做（3–5 条）
1. **烟-only Hush**：默认 **9 min** 自动恢复；危急/再探测打断；Hush≠关声光。  
2. **CO 禁止用户静音**。  
3. **同品牌无线本地级联**：P0 烟/CO → 已组网他机**同类型**本地声光跟报；**断云仍可用**。  
4. **本机 Hush 不压制他机**级联报警。  
5. **Matter/App 仅通知**；自检、低电、路径光（守 SED）、可关语音——与既有规格一并保留。

## B. 级联（互联）方案选项（供对照；产品已锁 Opt1）

| 选项 | 体验 | 认证影响 | 硬件/软件工作量 | 风险 |
|---|---|---|---|---|
| **Opt1 无线 RF 本地互联**（同品牌；Thread/自研安全报文） | 一机 P0 → 他机同类型本地声光；断云仍级联；用户可关「级联报警」 | 须按 UL/EN 互联相关条款与协议评估；不可写成有线消防总线替代；射频占空进 SED | 软：组网/密钥/报文/角色；硬：复用现有 802.15.4/Thread，无新互联脚 | 串网、功耗、延迟；异组隔离 |
| **Opt2 仅 Matter/Thread 状态通知** | 手机/生态通知；**他机不一定本地响** | 认证负担低于消防互联声称；但**不满足**竞品「一响全响」预期 | 软：Matter 事件；硬：无额外 | **竞争缺口**；断 Matter 则无全屋声 |
| **Opt3 有线互联脚** | 兼容旧 AC 红线网 | 美线安装与认证路径更重 | 网表**未预留**→改板+结构过孔；成本↑ | 一期明确**不做** |

**产品锁定结论（一句）**：**采用 Opt1（同品牌无线本地级联）；Matter 仅作通知补充（Opt2 能力保留但不替代 Opt1）；Opt3 一期不做。**

## C. 静音 / Hush 方案（对齐产品锁定）

| 项 | 规则（已锁） |
|---|---|
| 谁可静音 | **仅烟雾报警**；入口：本机 `BTN_TEST_MUTE`（App 近距 Hush 若做为可选，不得放宽 CO） |
| 时长 | 默认 **9 min**（落在 8–10）；超时**自动恢复** |
| 烟 / CO | 烟可 Hush；**CO 禁止 Hush**（无入口或拒绝） |
| 不可静音 / 打断 | 声光不可被用户**永久**关闭；危急升级/再探测**打断** Hush |
| 互连机 | 本机 Hush **不压制**已级联他机报警声 |
| 与红线关系 | **Hush ≠ 关机**；语音可关 ≠ 声光可关；传感器与判决在 Hush 窗内仍运行 |
| Listing | temporary silence for smoke / hush；**不写**可静音 CO |

**关键规则（一句）**：**仅烟可 Hush、默认 9 min 自动恢复且危急可打断；CO 一律禁止静音；本机 Hush 不压他机。**
