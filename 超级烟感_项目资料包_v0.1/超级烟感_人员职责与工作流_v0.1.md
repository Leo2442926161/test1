## 1. 目的

一人公司，多 Agent 同时干活。本文件是入职必读，用来避免抢同一目录、代签放行、对外发信。

- 群席位、主责、门禁、目录脊骨以本文为现行说明。
- 版本靠 git：谁改了职责，看本文件的提交记录。
- 产品范围、图纸、BOM、测试结论以各目录里已合入的文件为准。本文不复述那些交付物，也不编造尚未入库的 CAD、BOM 或报告。

---

## 2. 群与席位（现行）

两个群各 6 个席位。项目管理同时在两边，是项目群里的调度最高权。不要再加第七席。

| 群 | 席位 |
|---|---|
| 研发群「超级烟感·研发」 | Heiman、硬件、软件、结构、测试、项目管理 |
| 交付群「超级烟感·交付」 | 采购、增长、市场产品、设计制造、财务、项目管理 |

边界：

- Heiman 不在交付群。
- 市场产品不在研发群。
- G1、G2 和 PRD 走市场产品的私聊或交付群，不丢进研发群。
- Leo 不是群席位。花钱、合同、对外询价、范围变更只由 Leo 本人，或 Leo 写明授权的人。

## 4. 资料包目录脊骨

锁死。禁止新建顶层 `docs/`（#18 已关，该方案作废）。也不要把资料再搬去 `docs/02_硬件/` 或 `docs/03_结构/`；#20 旧正文里的 `docs/02_硬件/` 不要执行。

| 路径 | 谁可以推 |
|---|---|
| `超级烟感_项目资料包_v0.1/01_市场产品/` | 市场产品 |
| `超级烟感_项目资料包_v0.1/02_工程/硬件设计/` | 硬件 |
| `超级烟感_项目资料包_v0.1/02_工程/结构/` | 结构 |
| `超级烟感_项目资料包_v0.1/02_工程/软件/` | 软件 |
| `超级烟感_项目资料包_v0.1/03_采购财务/` | 采购、财务（见下） |
| `超级烟感_项目资料包_v0.1/04_测试/` | 测试 |
| `超级烟感_项目资料包_v0.1/ID概念/` | 设计制造 |
| `firmware/`（仓库顶层，不在资料包里面） | 软件 |

执行：

- 各岗只推自己的路径。交叉内容用链接指向对方目录，不复制一份正文。
- 同一路径禁止两个代理同时打开修改。`03_采购财务/` 虽由采购和财务共用，同一时刻也只允许一个代理改。
- 禁止无主总清扫：没有点名 Owner 的全库搬迁、删文件、改无关目录，不开工。
- 项目管理可以催办和指出放错的路径，自己不把文件改到别人的目录里。

## 6. 协作铁律

1. 花钱、合同、范围变更：仅 Leo。
2. 工程放行：测试和相关工程岗。项目管理和 Heiman 不代签。
3. 询价外发：Leo 自己发，或本次明确授权。工程和采购可以准备附件，不代发。
4. Issue 和 PR 的闭环跟催归项目管理。每条结论带 Owner 和截止日期。
5. 代码和文档必须进 git，才能当作已交付。聊天记录和未提交的草稿不算数。
6. 体验对标 Nest 的结果，对标不是抄袭。禁止 Nest 大环面，禁止照搬公开剧本和可识别光语。不点名 Nest 做对等宣称。灯光和语音是应达体验，不是第四主卖点。细则见 `01_市场产品/体验与IP约束_路径光语音_2026-10-22.md`（工程规避清单，不是法律意见）。
